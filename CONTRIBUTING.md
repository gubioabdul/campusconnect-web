# Contributing to CampusConnect

1. Fork the repository.
2. Create a focused feature branch, for example `feature/event-details`.
3. Make a focused change.
4. Run `npm test` before pushing.
5. Commit with a clear message.
6. Push the branch and open a pull request.
7. Respond to review feedback.
8. Merge only after CI passes and a maintainer approves the pull request.

Direct pushes to the default branch should be avoided for assessed project work.
